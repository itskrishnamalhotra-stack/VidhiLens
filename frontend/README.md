# VidhiLens frontend

Responsive React interface for VidhiLens. It supports private chats, model-driven replies, source-backed provision results, editable drafts, My cases, reviewer decisions, follow-up messages, and evidence.

## Local development

```powershell
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when Firebase is ready. Without Firebase values, the interface displays its private Colab demonstration login. Enter the current Cloudflare tunnel URL and the Krishna token generated by the notebook. The project reviewer selects the reviewer option and enters the separate reviewer token.

## Production build

```powershell
npm test
npm run build
```

The deployable Firebase Hosting output is placed in `dist`. `public/runtime-config.json` can provide the API URL without rebuilding the application:

```json
{ "apiBaseUrl": "https://your-backend.example" }
```

Never place the Colab demonstration token in that file or in source control. The token is entered by the user and held only in browser session storage.

## Firebase setup

1. Create or select a Firebase project.
2. Enable Google, Phone, and, if desired, anonymous sign-in in Firebase Authentication. Set up the reCAPTCHA domain and Firebase phone verification before allowing case submission.
3. Fill the public Firebase web values in `.env.local`.
4. Configure the backend with `LEGALAI_AUTH_MODE=firebase`, the same `FIREBASE_PROJECT_ID`, and Application Default Credentials or a service account on the server.
5. Add the Firebase Hosting origin to `LEGALAI_CORS_ORIGINS`.
6. Run `npm run build`, then deploy with the Firebase CLI.

The backend only accepts a phone-verified Firebase identity for internal case submission. Reviewer access needs the `nyayasetu_admin` custom claim set by the Firebase project owner. Do not grant it through the frontend. Internal submission never files a report with police or a government portal.

The frontend never contains a Firebase service-account key. Firebase web configuration values identify the project and are expected to be public.
