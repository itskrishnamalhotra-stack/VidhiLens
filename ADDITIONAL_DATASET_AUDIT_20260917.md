# Additional dataset intake — 17 September 2026

Eight files from five Hugging Face repositories were downloaded at pinned revisions and SHA-256 hashes, screened, and indexed in the **same canonical SQLite master**. The new tables are `additional_candidate_source` and `additional_candidate_row`. Every row retains its original JSON, source file and row number, extracted input, publisher section hints, and screening issues. All 10,892 new rows have `training_approved=0`; the existing 3,022 pilot train records are unchanged. The file manifest is `additional_candidates_manifest.json`, and the machine-readable screening report is `additional_candidates_screening_report.json`.

| Source | Indexed | What the full-file screen found | Decision |
|---|---:|---|---|
| [NariRaksha-1K](https://huggingface.co/datasets/vikhram-labs/NariRaksha-1K) | 1,000 | Only 12 distinct legal-context strings; repeated synthetic narrative templates. Some labels demonstrably conflict with official section titles: its “BNS 316 (cheating)” should be BNS 318; it describes BNS 73 as outraging modesty although BNS 73 concerns publishing court proceedings. A cyberstalking template cites IT Act 66E without facts about capturing a private-area image. | Good topic inventory, poor direct legal-label source. Apache 2.0. |
| [Complaint-Relevant-BNS](https://huggingface.co/datasets/navaneeth005/complaint-relevant-bns) | 325 | 126 use the same generic allegation sentence; 61 include an explicit section answer in the input; 56 contain an apparent incident date before BNS commenced. Some city/state pairs conflict. Repository has no stated licence. | Hold. Section-output format alone does not make it a clean complaint corpus. |
| [Nyaya Train v3](https://huggingface.co/datasets/NyayaLabs98/nyaya-train-v3) | 5,292 train + 280 val + 857 test = 6,429 | Every record's metadata says `verified: false`. Only 1,296 train records have BNS/IT Act source-section hints. Many questions are general legal QA, and prompts include supplied law passages that must be removed for a complaint-input task. A narrow 19-section, noncitation, 25-word screen yielded 28 train questions for source-grounded review. | Best new review pool. Apache 2.0. Keep the publisher test split out of training. |
| [Fraud & Cyber Safety](https://huggingface.co/datasets/sidddd625/adaption-fraud-and-cyber-safety) | 2,658 | Useful multilingual cyber-fraud questions; 60 exact repeated inputs. Citations occur in generated answers, not in a verified label field. Dataset card declares no licence. | Topic and language research only pending usage rights and legal checking. |
| [Nyaya Statute DB](https://huggingface.co/datasets/NyayaLabs98/nyaya-statute-db) | 358 BNS + 122 IT Act | All 358 BNS section numbers and titles match the local index. Its IT file omits sections 50, 52 and 61 from the local index and still gives IT Act 66A its old offence text and imprisonment summary. Our official-law record marks 66A omitted and nonrecommendable. | Third-party cross-check only. Never override official India Code text/status. |
| [Open India Law](https://huggingface.co/datasets/vaquill/open-india-law) | 0 | The publisher lists millions of judgments, but dataset files require accepting gated conditions and sharing contact information. Judgments also contain allegations, procedure and outcomes that cannot automatically be turned into clean complaint labels. | Not acquired or imported. Reassess only if access and targeted processing make sense. |

The verified legal source remains the [official BNS text](https://www.indiacode.nic.in/bitstream/123456789/20062/1/a2023-45.pdf) and [current official IT Act text](https://upload.indiacode.nic.in/view-casepdf?id=AC_CEN_45_76_00001_200021_1517807324077&type=act), together with the project's amendment/status sources. Matching an existing section number is only a schema check; it does not prove the section applies to the facts.

`data_drafts/additional_nyaya_v3_review_shortlist.jsonl` contains the 28 best automatically selected **review candidates**, all explicitly pending review. None enters the LoRA export. The first six previously indexed public files contribute 6,681 source rows, so the master now indexes **17,573 public-source candidate rows**, of which **21 previously corrected rows** are actually approved training examples. The 10,892 new rows add zero approved examples today.
