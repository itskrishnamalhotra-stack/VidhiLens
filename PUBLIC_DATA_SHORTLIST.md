# GitHub, Hugging Face and Kaggle data search

Checked 17 September 2026 for Krishna Malhotra's BNS + IT Act complaint assistant. Publisher row counts and licence claims are leads, not an audit of the underlying files. No source below is silently counted as accepted complaint training data.

## Current decision

Kaggle has useful Indian legal and crime datasets, but this search has **not confirmed a directly usable, large, current BNS-plus-IT-Act complaint-to-section dataset**. The strongest complaint-text lead is `Complaint_and_Sections`, whose 47,329 labels are IPC and whose files require access conditions. The next practical source audit should obtain that file if access is available, inspect a stratified sample, map only relevant IPC labels against official BNS text, and retain only cases whose privacy and legal elements can be reviewed. No automatic IPC→BNS relabeling is allowed.

Large row counts from generic QA or court corpora must not be added to the complaint-training count. The local accepted set and third-party candidate files are described in `DATA_INVENTORY.md`; downloaded file hashes and licence cards are pinned in `external_candidates_manifest.json`.
